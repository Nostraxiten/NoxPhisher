## Overview

**NoxPhisher** is a passive reconnaissance framework designed to audit data exposure in web browsers. When a visitor accesses the link generated by the tool, they see a simulated loading screen before being automatically redirected to a safe destination (Google by default).

During this interval, the application collects network, location, and hardware information through known vulnerabilities and passive extraction methods in the browser, consolidating all the information in a local SQLite database.


## Technical Capture Vectors

NoxPhisher passively collects the following parameters without requiring additional user interaction:

*   **Network Identification:**
    *   Real public IP address via the `CF-Connecting-IP` header.
    *   Filtering and detection of private local addresses (IPv4 and IPv6) via the WebRTC protocol (WebRTC leak).
*   **Advanced Geolocation:** Country, region, city, precise geographic coordinates (latitude/longitude), Internet Service Provider (ISP), and Autonomous System (ASN).
*   **Hardware Fingerprint:** Browser name and identifier, host operating system, screen resolution, available RAM, and number of logical CPU cores.
*   **Audit Log:** Exact timestamp with UTC precision.

## Parameters and Usage Options

To view the help menu:
```bash
python noxphisher.py -h
```

### CLI Options Table

| CLI Argument | Description | Default Value |
| :--- | :--- | :---: |
| `--qr` | Generates and displays a QR code for the tunnel link directly in the terminal. | Disabled |
| `--window N` | Sets the time in seconds to consider a record a duplicate (deduplication). | `60` |
| `--port N` | Specifies the local server's listening port. | `8080` |
| `--view [N]` | Queries and displays the last N captures from the database in the terminal without starting the server. | `50` |

### Practical Usage Examples

```bash
# Standard server and tunnel launch
python noxphisher.py

# Start the server showing the QR code for mobile devices
python noxphisher.py --qr

# Change the listening port and set a 5-minute (300s) deduplication window
python noxphisher.py --port 9090 --window 300

# Query the last 20 captures stored in the local database
python noxphisher.py --view 20
```

## Implementation Notes and Technical Details

*   **Tunnel Management:** The public tunnel is dynamically launched by calling the local `cloudflared` executable. No prior login or account on the Cloudflare platform is required.
*   **Deduplication Logic:** To prevent log flooding from continuous page reloads, the tool implements a composite key (Public IP + Fingerprint). If a key already exists within the configured time window (`--window`), the record is discarded from the database.
*   **Termux / Notifications Integration:** The tool uses `plyer` to send native notifications on Windows, Linux, and macOS. On Termux, the API package is recommended.
